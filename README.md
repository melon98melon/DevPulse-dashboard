# DevPulse

 
A responsive marketing page for **DevPulse**, a cloud infrastructure monitoring and management platform. This project was developed using HTML5 and CSS3 to showcase cloud services, pricing plans, and user registration functionality.

 

## Overview

 
DevPulse is a fictional cloud infrastructure service provider that offers:

 

- Real-time performance monitoring
- Log aggregation and analysis
- Automated security monitoring
- Self-healing infrastructure solutions

 
The website is designed to provide visitors with product information, pricing options, and a registration form for obtaining sandbox API credentials.

 

 

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Variables
- Responsive Design Principles

## User Stories

 

### Story 1: Value Proposition & Sticky Navigation

As an infrastructure engineer landing on DevPulse, I want to review core value metrics, access landmark navigation links, and see a high-contrast "Deploy Free Cluster" CTA above the fold.

 

### Story 2: Infrastructure Feature Grid

As a DevOps lead, I want to scan key platform capabilities (Latency Tracking, Log Aggregation, Auto-Remediation) in a structured content layout.

 

### Story 3: Compute Tier Comparison

As an engineering manager, I want to compare three cluster hosting tiers ("Developer", "Pro Cluster", "Enterprise Dedicated") with an elevated visual badge on the most popular plan.

 

### Story 4: Workload Estimation Form

As a systems architect, I want to enter our node count and log throughput requirements into a form with numeric bounds to verify tier compatibility.

 

### Story 5: API Provisioning Lead Capture

As a developer, I want to submit a pre-registration form with required fields to receive API sandbox provisioning details.

##  

 

## User Funnel

 

1. User enters the website and immediately sees:

- DevPulse branding/logo
- Sticky navigation menu
- Platform description
- Core business metrics
- High-contrast "Deploy Free Cluster" CTA button

  2. User scrolls to the Features section where:

- Infrastructure capabilities are displayed
- Feature descriptions are arranged in a structured layout
- Supporting imagery is shown
- A highlighted CTA encourages continued exploration

  3. User clicks the CTA and is taken to:

- Pricing tier comparison cards
- Developer, Pro Cluster, and Enterprise Dedicated plans
- Recommended plan highlighted visually

  4. User selects a preferred hosting tier and proceeds to:

- Workload estimation and registration form

  5. User submits contact and infrastructure information to:

- Receive API sandbox provisioning details
